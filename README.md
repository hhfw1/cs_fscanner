# CodeStudio Fingerprint Scanner 🔍

A lightweight fingerprint scanner script for FiveM servers.
Works seamlessly with QB-Core, ESX, Qbox, or even standalone mode.

This script allows players to scan another person’s fingerprint in-game.
When used, it will print the scanned user’s information directly, making it useful for police roleplay, identity verification, or custom server mechanics.

</br>

## 🖥️ Usage
- Use `/fscan` if the command is enabled.
- Press `H` if the keybind is enabled.
- If item mode is enabled, make sure you have the `finger_scanner` item in your inventory.

*(These options can be edited in the config to match your server’s needs.)*
